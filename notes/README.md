# Automated Credit Scoring System

## Overview
This project provides an automated credit scoring system for financial institutions. It features a React TypeScript frontend with a Python Flask backend to process and analyze CSV financial data.

## Features
- CSV file upload and parsing
- Column visualization and selection
- Credit score calculation engine
- Secure data processing
- Modern responsive UI
